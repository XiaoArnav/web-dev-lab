# Problem 14: Responsive Design and Lighthouse Performance Audit

## Aim
To build a fully responsive webpage optimized for mobile and desktop screens and verify performance, accessibility, best practices, and SEO using Google Lighthouse audit.

## Concepts Covered
- Responsive viewport configuration and fluid layout
- Mobile-first CSS media queries
- Color contrast ratios and accessibility standards
- Chrome DevTools Lighthouse audit for web performance

## Steps
1. Set up a semantic HTML document with meta viewport and meta description.
2. Author mobile-first styles using CSS Grid and Flexbox for adaptive components.
3. Add media queries for tablet and desktop screen sizes.
4. Run the Lighthouse audit in Chrome DevTools to verify high scores across all four categories.
