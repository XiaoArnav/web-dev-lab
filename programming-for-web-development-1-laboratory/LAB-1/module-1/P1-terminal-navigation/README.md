# Problem 1: Project Folder and Terminal Navigation

## Aim
To learn basic terminal commands for creating project folders and navigating directories.

## Commands Used
- `pwd` - check current directory
- `mkdir` - create a new folder
- `cd` - navigate between folders
- `touch` - create empty files
- `ls` - list files in the directory

## Steps
1. Created the project directory and navigated into it:
```bash
mkdir P1-terminal-navigation
cd P1-terminal-navigation
```

2. Created the starter HTML and CSS files:
```bash
touch index.html styles.css README.md
```

3. Checked the files:
```bash
ls -la
```
