# Problem 7: Design tokens and typography system in CSS

## Aim
To implement a reusable design system using CSS custom properties (variables) for colors, typography, spacing, and component tokens.

## Concepts Covered
- CSS custom properties (`:root`) for color palette and spacing tokens
- Typography scale and hierarchy (`h1`, `h2`, `h3`, `p`, `.lead`, `small`)
- Modular component styling using tokens (cards, buttons)
- Clean, semantic HTML structure to showcase the tokens

## Steps
1. Created `index.html` containing sections for color palette swatches, typography hierarchy, and sample UI components.
2. Defined global CSS variables in `:root` within `styles.css` for primary, secondary, text, background, and spacing values.
3. Applied the custom properties using `var()` to style headings, cards, and buttons consistently.
4. Tested the design token system in the browser to ensure consistent visual hierarchy.
