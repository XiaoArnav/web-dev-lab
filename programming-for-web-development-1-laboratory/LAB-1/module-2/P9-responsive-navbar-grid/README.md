# Problem 9: Responsive navbar and card grid using Flexbox

## Aim
To create a responsive navigation bar and a flexible card grid layout using CSS Flexbox and media queries.

## Concepts Covered
- `display: flex` with `justify-content` and `align-items` for navbar alignment
- `flex-wrap: wrap` and `flex: 1 1 250px` for responsive card grids
- `@media (max-width: 600px)` media query to stack navigation links on smaller screens
- Column flex layout for card internals (`display: flex; flex-direction: column`)

## Steps
1. Created `index.html` containing a navigation bar, hero header, and three course cards.
2. Added `styles.css` using Flexbox for space-between navigation and wrapping card grid.
3. Added a media query to stack navbar items vertically on mobile viewports.
4. Tested responsiveness across different browser window widths.
