# Problem 5: Semantic bio page

## Aim
To create a personal biography page using semantic HTML5 elements and simple CSS.

## HTML Elements Used
- `<header>` - page title and subtitle
- `<main>` - main content area
- `<article>` - primary biography content
- `<section>` - grouped sections for About, Education, and Interests
- `<aside>` - sidebar for quick facts
- `<footer>` - copyright and page footer

## Steps
1. Created `index.html` using semantic HTML5 elements without generic wrapper divs.
2. Structured content into header, main article, aside sidebar, and footer.
3. Added `styles.css` for clean typography, spacing, and a simple two-column layout.
4. Tested the page in the browser to ensure proper layout and readability.
