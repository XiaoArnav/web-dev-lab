# Problem 6: Full portfolio page structure in semantic HTML

## Aim
To build a complete personal portfolio layout using semantic HTML5 tags and clean CSS styling.

## HTML Elements Used
- `<nav>` - navigation bar with page section links
- `<header>` - hero banner with title and call-to-action button
- `<main>` - container for main content sections
- `<section>` - distinct sections for About, Skills, Projects, and Contact
- `<article>` - individual project cards within the projects section
- `<form>` - interactive contact form with inputs and submit button
- `<footer>` - page footer and copyright notice

## Steps
1. Structured `index.html` with a navbar, hero header, content sections, and footer.
2. Used semantic tags like `<nav>`, `<section>`, `<article>`, and `<form>` instead of generic `<div>` containers.
3. Added `styles.css` to handle navigation styling, hero spacing, card layouts, and form inputs.
4. Verified layout and navigation links across the page in the browser.
