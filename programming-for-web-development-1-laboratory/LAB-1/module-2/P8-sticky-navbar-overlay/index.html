Understanding CSS Positioning

CSS positioning allows elements to be taken out of normal document flow or pinned during viewport scrolling:

  • Static: Default flow order of HTML elements.
  • Relative: Positioned relative to normal flow; establishes containing block for absolute children.
  • Absolute: Placed precisely relative to the nearest positioned ancestor.
  • Sticky: Toggles between relative and fixed depending on scroll position.
