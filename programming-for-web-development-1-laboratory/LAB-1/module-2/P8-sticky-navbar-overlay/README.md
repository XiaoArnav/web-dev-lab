# Problem 8: Sticky navbar and card overlay using CSS positioning

## Aim
To implement a sticky navigation bar and card overlay effects using CSS positioning.

## Concepts Covered
- `position: sticky` and `top: 0` for keeping the navbar pinned during scroll
- `position: relative` on the card image container
- `position: absolute` for corner badge and hover overlay
- `z-index` to keep the navbar above page content

## Steps
1. Created `index.html` with a navbar, hero header, and cards featuring corner badge and hover overlay.
2. Added `styles.css` using `position: sticky` on `.navbar` so it stays at the top when scrolling.
3. Used `position: relative` on `.card-img` and `position: absolute` on `.badge` and `.overlay`.
4. Verified sticky scrolling and hover effects in the browser.
